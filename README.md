# clinic_project2
Electronic Clinic System

Project Description

Electronic clinic system developed using PHP and MySQL.

Project Idea

The system allows patients to:

- Register
- Login
- Send consultations

The doctor can:

- View consultations
- Reply to patients

Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP

How to Run

1. Start Apache and MySQL in XAMPP.
2. Import clinic_project.sql into phpMyAdmin.
3. Place project folder inside htdocs.
4. Open:
   http://localhost/clinic_project
